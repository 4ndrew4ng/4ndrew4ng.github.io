Manual Exploit Chaining & Privilege Escalation

Executive Summary

To validate advanced manual exploitation techniques, I completed a complex boot-to-root engagement. This exercise required bypassing automated exploitation frameworks (e.g., Metasploit) to manually chain multiple service misconfigurations, exfiltrate protected credentials, and manipulate environment variables for root-level privilege escalation.

Core Competencies Validated

1. Cross-Protocol Exploit Chaining

  • Enumerated exposed SMB and NFS (RPCbind) shares to map the target's internal file structures and identify network-mounted directories.
  • Leveraged banner grabbing via Netcat to identify a vulnerable instance of ProFTPd (1.3.5).
  • Exploited the mod_copy module vulnerability to perform unauthenticated lateral movement of sensitive files, ripping a private SSH (id_rsa) key from a protected directory and dropping it into a globally accessible NFS mount.

2. Advanced Privilege Escalation ($PATH Hijacking)

  • Interrogated the file system to isolate custom SUID (Set User ID) binaries executing with root permissions.
  • Utilized the strings utility to reverse-engineer the binary's execution flow, identifying a vulnerability where system commands were called without absolute pathing.
  • Authored a malicious shell payload and manipulated the system's $PATH environment variable to hijack the execution flow, successfully forcing the SUID binary to spawn a persistent root shell.

Key Takeaways

"Security is only as strong as its weakest protocol configuration. A vulnerability in an FTP service can be weaponized to move files, but chaining that with an exposed Network File System and a poorly coded SUID binary is what turns a minor misconfiguration into a total system compromise. True offensive capability lies in understanding how discrete services interact."
