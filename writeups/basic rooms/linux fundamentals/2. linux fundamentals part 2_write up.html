TryHackMe Room Completed

Linux Security Architecture & File System Interrogation

Executive Summary

As a prerequisite for advanced host-based privilege escalation, I completed a technical module focused on Linux security architecture. This engagement required establishing encrypted remote connections, manipulating core access control lists (ACLs), and enumerating critical system directories to identify potential attack vectors.

Core Competencies Validated

1. Secure Remote Administration & Cryptography

  • Established encrypted remote terminal sessions utilizing the Secure Shell (SSH) protocol, bypassing cleartext transmission risks associated with legacy protocols.
  • Navigated the host OS natively, deploying specialized flags/arguments to modify standard command execution and extract hidden file structures.

2. Discretionary Access Control (DAC) Analysis

  • Interrogated file and directory permissions mapping to Owner, Group, and Global boundaries.
  • Identified read/write/execute (rwx) misconfigurations that could be leveraged for lateral movement or data exfiltration.
  • Executed user-context pivoting using the su utility to validate authentication boundaries and environment variable inheritance.

3. OS Directory Enumeration

  • Mapped the standard Linux hierarchy to identify high-value targets, specifically focusing on configuration stores (/etc) and volatile logging directories (/var/log).
  • Utilized world-writable temporary directories (/tmp) to simulate secure payload staging scenarios.

Key Takeaways

"Privilege escalation is entirely dependent on understanding what you are allowed to touch and what you are blocked from reading. By mastering Linux Discretionary Access Controls and understanding exactly where an OS hides its credentials and logs, an attacker can silently pivot through a system without triggering administrative alarms."
