TryHackMe Room Completed

Network Enumeration & Vulnerability Discovery

Executive Summary

To validate proficiency in active reconnaissance, I completed a technical engagement utilizing the industry-standard network mapping framework, Nmap. This exercise required executing stealth-based host discovery, mapping exposed attack surfaces, and extracting exact service versions to identify exploitable vulnerabilities.

Core Competencies Validated

1. Stealth TCP/UDP Port Scanning

  • Executed half-open TCP SYN Scans (-sS) utilizing root-level packet crafting to map network ports while minimizing full connection logs on the target system.
  • Analyzed and differentiated the behaviors of connectionless UDP Scans (-sU) and full 3-way handshake Connect Scans (-sT) to adapt to varying target environments.

2. Service Identification & Evasion

  • Deployed deep service interrogation (-sV) to extract exact software banners (e.g., Lighttpd 1.4.74), correlating exposed ports to specific CVEs for exploit staging.
  • Bypassed firewall ICMP restrictions using the Assume Alive (-Pn) flag, ensuring rigorous scanning of non-responsive but active targets.
  • Manipulated scan velocity via Timing Templates (-T) to simulate both noisy, aggressive mapping and quiet, stealth-focused IDS evasion.

Key Takeaways

"Reconnaissance dictates the success of an engagement. Finding an open port is trivial; extracting the exact software version running on that port, while managing packet flow to avoid triggering a Web Application Firewall or Intrusion Detection System, is the defining skill of a professional penetration tester."
