Foundational Training: HTTP Mechanics & API Manipulation

Module Objective: Validated foundational mechanics of web application security. A browser is merely a translator. To truly secure—or compromise—a web application, one must speak its native language. By bypassing standard graphical interfaces to directly manipulate backend logic, craft raw HTTP requests, and analyze state-management mechanisms, I demonstrated the ability to engage directly with the backend code where critical vulnerabilities reside.

1. HTTP Verbs & API Manipulation

Manually crafted and executed GET, POST, PUT, and DELETE requests to interface directly with backend routing logic. Injected explicit URL Query Strings and Body Parameters to forge authentication attempts, modify remote user records, and execute unauthorized resource deletion.

2. Status Code & Error Analysis

Analyzed HTTP server responses to map backend infrastructure health and permission structures. Differentiated between Client-side authorization failures (401/403) and Server-side logic crashes (500/503) to effectively identify potential vulnerability points within the application's attack surface.

3. Headers & State Management

Analyzed HTTP request/response headers, specifically focusing on Content-Length validation and User-Agent modification. Demonstrated an understanding of stateless protocol constraints and the reliance on Cookies for session management, a critical prerequisite for identifying Session Hijacking and Cross-Site Request Forgery (CSRF) vulnerabilities.
