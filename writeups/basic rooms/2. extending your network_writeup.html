Foundational Training: Extending Your Network

Module Objective: Validated core competencies in enterprise network architecture and perimeter defense. Mastering firewall configurations, VLAN segmentation, and VPN tunneling is critical for understanding how to secure internal networks, mitigate active DoS attacks, and securely route traffic across Layer 3 hardware.

1. Firewall Configuration & Attack Mitigation

Differentiated between Stateless (Layer 3) and Stateful (Layer 4) firewall operations. Successfully utilized a network simulator to identify an active Denial of Service (DoS) attack, extracted the malicious Source IP, and deployed a targeted packet-dropping rule on Port 80 to stabilize the web server.

2. Secure Tunneling (VPNs & IPsec)

Analyzed how Virtual Private Networks (VPNs) secure data in transit. Examined the IPsec framework for establishing fully encrypted, routable tunnels over public infrastructure, contrasting it with legacy protocols like PPP to understand the evolution of data authentication.

3. Enterprise LAN Segmentation

Mapped the flow of packets across multi-layer topologies using Routers and Switches. Analyzed the implementation of VLANs (Virtual Local Area Networks) on Layer 3 switches to enforce strict logical network segmentation and internal security compliance.
